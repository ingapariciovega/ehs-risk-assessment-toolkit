# EHS Risk Assessment Toolkit

**Status: editable templates for an educational assessment workflow.**

The toolkit organizes hazard observations, existing controls, proposed actions, accountable roles and closure evidence. It does not automatically declare an activity safe or determine legal compliance.

## Files

- `hazard-register.md`: blank structured register and one clearly fictional example.
- `assessment-template.json`: a machine-readable record template.
- `action-review.md`: how to distinguish a proposed control, implemented control and verified outcome.

## Working approach

Start with task observation and worker input. Describe the hazardous situation and credible consequence; record existing controls separately from proposed actions. Assign responsibility, due date and evidence. Review effectiveness before closure. For actual use, competent site personnel must establish context, risk criteria and applicable requirements.

No numeric matrix is supplied as a universal measure of risk; a scoring system requires agreed definitions and should not replace critical-control verification.

Reference: [OSHA — Hazard identification and assessment](https://www.osha.gov/safety-management/hazard-identification) and [Hazard prevention and control](https://www.osha.gov/safety-management/hazard-prevention), accessed 2026-10-01. These are general learning references, not a claim of Mexican regulatory compliance.
